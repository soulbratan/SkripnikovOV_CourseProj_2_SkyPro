## Примеры использования:
1. В пакете *'src'* созданы модули: *'external_api.py'*, *'storage.py'*, *'utils.py'*, *'vacancies.py'*.
2. Также в структуре проекта создан пакет *'tests'* для функций тестирования, директория *'data'* для хранения файлов с вакансиями, и модуль *'main.py'* для основной логики проекта.
2. В модуле *'external_api.py'* определены абстрактный класс *'VacancyAPI'*, и дочерний от него класс *'HeadHunterAPI'*, который производит подключение к API HH.ru и получает вакансии по поисковому запросу.
3. В модуле *'vacancies.py'* определен класс *'Vacancy'* для работы с вакансиями. Экземпляр класса имеет следующие атрибуты: заголовок, ссылка, зарплата, описание. Класс поддерживает методы сравнения вакансий (через магические методы), метод валидации данных для инициализации атрибутов зарплаты.
4. В модуле *'storage.py'* определены абстрактный класс *'VacancyStorage'*, и дочерний от него класс *'JSONSaver'*. Класс предназначен для работы с json данными. Класс поддерживает методы чтения/записи данных в файл, добавление/удаление вакансии, проверка на дубликат.
5. В модуле *'utils'* определена функция *'f_by_kwrd'* которая принимает список с вакансиями и ключевое слово, и возвращает отфильтрованный список.
6. В модуле *'utils'* определена функция *'salary_range'* которая принимает список с вакансиями, и возвращает отфильтрованный список по диапазону зарплат. Диапазон зарплат запрашивается в ходе выполнения функции.
7. В модуле *'utils'* определена функция *'top_vacancies'*, которая принимает целое число и список с вакансиями, сортирует этот список по зарплате, и возвращает отсортированный топ вакансий (количество вакансий - целое число).
8. В модуле *'utils'* определен декоратор *'print_enumerated_list'* для вывода пронумерованного списка вакансий (в данном проекте декоратор применяется для функции *'top_vacancies'*).
9. В модуле *'main.py'* определена функция взаимодействия с пользователем *'user_interaction'*. Функция объединяет все классы и функции в единую программу.
